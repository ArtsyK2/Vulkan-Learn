# Vulkan Learning

A hands-on exploration of the Vulkan graphics API.

## Goals

- Understand Vulkan's explicit GPU programming model
- Learn graphics pipeline construction
- Understand synchronization and command submission
- Implement resource management
- Build a small rendering engine from scratch
